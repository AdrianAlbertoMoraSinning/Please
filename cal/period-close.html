Close Fiscal Period

This creates a posting lock for the selected date range.
Once closed, new financial events and Journals dated inside this period are rejected. Reopening requires a documented reason and chronological control.

Reopen Fiscal Period

Reopening removes the exact date-range lock but never rewrites posted Journals.
If a later period is closed, it must be reopened first. After corrections, prepare and close this period again to create a new close version.
