# Data Custody Model

## Customer owns / controls
- Accounting database
- Accounting documents and receipts
- Customer/vendor records
- Bank imports
- Tax working papers
- Backups and archive copies
- Production business credentials and access approvals

## Developer retains
- Reusable source code / accounting engine
- Generic database migrations and deployment tooling
- Non-client-specific UI components and know-how

## Recommended contractual language themes
- Customer Data remains the customer's property.
- Developer access is limited to authorized support/maintenance purposes.
- Customer can revoke access and export its data.
- Customer is responsible for accounting/tax decisions and professional review.
- Backup/retention responsibilities are explicitly assigned rather than assumed.
- Security incident and subprocessor obligations are explicitly documented.
