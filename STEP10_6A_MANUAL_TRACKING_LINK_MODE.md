# STEP 10.6A — Manual Tracking Link Mode

Temporary operating mode while PLEASE waits for access to verify its email sending domain.

- Customer receives the Request Reference on-screen.
- Customer can open or copy the secure tracking link immediately.
- Customer can later recover tracking using Request Reference + Email.
- PLEASE Administration can open or regenerate/copy a secure tracking link from Service Requests and send it manually by email, SMS or WhatsApp.
- Automatic Resend email remains optional and will activate later when `RESEND_API_KEY` and `PLEASE_EMAIL_FROM` are configured.
- No SQL changes are required.
